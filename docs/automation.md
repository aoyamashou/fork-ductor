# 自动化

所有自动化任务都在 ductor 的 asyncio 进程中运行，结果通过消息总线发送到指定 Telegram 聊天或话题。运行前请先完成 Telegram 用户与群组白名单配置。

## 定时任务

机器人中的 `/cron` 可查看、启用或暂停任务。任务定义保存在 `~/.ductor/cron_jobs.json`，每项包含计划、提示词、目标聊天和可选模型覆盖。时区由 `user_timezone` 决定；为空时使用系统时区。定时任务可选择成功时静默，并可开启投递重试。

## Webhook

Webhook 服务器默认监听本机地址。`wake` 模式把事件注入现有聊天，`cron_task` 模式以独立任务运行。配置中的 Token、请求大小与速率限制应与调用方一致。若要让外部服务访问，请自行配置安全的反向代理或私有网络。

## 心跳

启用 `heartbeat.enabled` 后，智能体会按间隔检查工作区，并可向指定的 Telegram 聊天或话题发送有价值的结果。`quiet_start` 和 `quiet_end` 控制静默时段，`ack_token` 用于表示无需发送消息。

## 后台会话与任务

`/session` 创建命名后台会话，后续可用会话名继续；`/tasks` 查看或取消委派任务。后台任务可以并行运行，但同一聊天的结果仍通过消息总线有序发送。任务状态保存于 `~/.ductor/tasks.json`。

## 清理

清理观察器按配置定期删除超过保留期的 Telegram 媒体文件、输出文件和 API 文件。保留天数位于 `cleanup` 配置段。清理不删除会话、记忆和任务注册表。
