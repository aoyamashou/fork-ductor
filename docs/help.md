# Telegram 机器人命令

机器人命令仍使用英文指令名，以便与 Telegram 的命令菜单保持一致；说明、按钮和结果使用简体中文。

## 会话与模型

| 命令 | 说明 |
| --- | --- |
| `/start` | 打开欢迎页面 |
| `/help` | 显示命令总览 |
| `/model` | 查看或切换模型与提供商 |
| `/effort` | 设置推理强度 |
| `/new` | 为当前聊天建立新会话 |
| `/reset` | 重置当前提供商的会话 |
| `/status` | 查看模型、会话、消息数和费用等状态 |
| `/memory` | 查看主记忆 |

`/new` 使用配置的默认提供商，并清空当前 Telegram 聊天或话题对应的会话；其他提供商的会话保留。`/reset` 只清空当前活动提供商的会话。

## 运行控制

| 命令 | 说明 |
| --- | --- |
| `/stop` | 停止当前运行，并丢弃等待中的消息 |
| `/interrupt` | 只中断当前运行，保留等待队列 |
| `/diagnose` | 查看模型、配置和最近日志的诊断信息 |
| `/restart` | 重启机器人 |
| `/upgrade` | 检查并执行版本升级 |

## 后台工作与文件

| 命令 | 说明 |
| --- | --- |
| `/session` | 启动或管理命名后台会话 |
| `/tasks` | 查看、取消或清理后台任务 |
| `/cron` | 查看、启用或暂停定时任务 |
| `/showfiles` | 浏览机器人工作区文件 |
| `/info` | 查看项目资料和帮助链接 |

命名会话在当前聊天之外运行，可通过其名称继续对话。后台任务完成后，结果会发回原始 Telegram 聊天或话题。

## 子智能体

主智能体可管理拥有独立 Bot Token 和工作区的 Telegram 子智能体。相关命令会在机器人的多智能体命令菜单中显示；终端中可用 `ductor agents list`、`ductor agents add <名称>` 和 `ductor agents remove <名称>` 管理。
