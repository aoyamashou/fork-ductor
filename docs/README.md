- [配置](config.md)：配置文件、字段与热更新边界。
- [系统概览](system_overview.md)：消息从 Telegram 到模型 CLI 的路径。
- [架构](architecture.md)：进程、会话、异步任务与消息总线。
- [自动化](automation.md)：定时任务、Webhook、心跳和清理。
- [开发快速入门](developer_quickstart.md)：本地开发与测试。

`docs/modules/` 提供当前 Telegram/macOS 架构的中文模块说明。
